# skills

My personal skills

## Reference depth

A skill may reference other skills, but only one level deep.

- **Hubs** (`pragmatic-engineering`, `writing-typescript`,
  `setting-up-typescript-projects`) may name leaf skills.
- **Leaves** (`writing-maintainable-code`, `writing-code-comments`,
  `writing-commit-messages`, `writing-pull-request-descriptions`, `technical-writing`,
  `test-driven-development`, `setting-up-node-projects`, `setting-up-python-projects`)
  name no other skill.
- A hub never names another hub.
